# Videographr 0.1.0-alpha.1

This is a local source-alpha candidate for contributors and methods evaluators.
It has not been committed, tagged, pushed, or published.

## Included

- Session context, operating mode, retention information, and scoped consent
- One continuous local recording per session
- Direct technical capture observations and explicit missing states
- Time-linked reflection notes
- Consent-scoped, metadata-only `.videographrstudy` export with membership,
  digests, and provenance
- Device-owner authentication and local artifact protection
- German-language reference catalogue

## Evidence boundary

The candidate does not provide validated pedagogical, speech-intelligibility,
learning, or teaching-quality measures. Experimental hypotheses require protocol
metadata, remain visibly unvalidated, and do not control readiness or authority.

## Build

```bash
bash scripts/verify_release.sh
open App/Unterrichtsvideographie.xcodeproj
```

The app bundle version is `0.1.0 (1)`. No signed IPA, TestFlight build, App Store
package, backend, or cloud service is included.

The study package does not contain the recorded or imported MP4. The app has no
separate video-export operation in this candidate. Share-attempt state remains in
the local session record.

## Open validation

- Physical-device camera, microphone, audio-route, interruption, background,
  file-protection, storage, thermal, and 60-minute recording checks
- Managed-device and institutional security review
- Human-rater validation of experimental hypotheses
- Evaluation of reflection or educational outcomes
